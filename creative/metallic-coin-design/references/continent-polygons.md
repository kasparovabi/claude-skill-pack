# 6 Kıta Poligon Koordinatları (Antarktika Hariç)

Koordinat sistemi: `(longitude, latitude)` → `(x, y)` piksel dönüşümü:
```python
def ll2px(lon, lat, cx, cy, r):
    x = cx + int((lon / 180) * (r - 15))
    y = cy - int((lat / 90) * (r - 15))
    return x, y
```

## Kullanım Notu

- Merkez (cx, cy) para merkezi; r harita yarıçapı (genelde ana R - 150px)
- Kıta fill: gümüş için `(72,72,78,240)`, bronz için `(65,38,15,240)`
- RGBA overlay üzerinde çizin, `Image.alpha_composite()` ile birleştirin
